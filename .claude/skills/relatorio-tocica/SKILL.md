# Relatório TOCICA

Entrada: descrição do desvio/evento. Se faltar dado essencial, pergunte antes de redigir.
Se houver template TOCICA no Gmail/Drive, busque-o via MCP e siga-o; caso contrário use a estrutura abaixo.

Saída (pt-BR, linguagem objetiva e factual, sem culpabilizar pessoas):
1. Identificação: data, hora, local, equipamento/área, relator
2. Descrição do evento (fatos em ordem cronológica)
3. Classificação (tipo, potencial de severidade)
4. Causas (imediatas e raiz — ex.: 5 porquês)
5. Ações imediatas tomadas
6. Ações corretivas/preventivas (responsável, prazo)
7. Evidências anexas

Não invente informações ausentes — marque "A informar".
