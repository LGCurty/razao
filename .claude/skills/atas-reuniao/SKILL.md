# Ata de reunião

Entrada: transcrição (texto/arquivo; se for vídeo, peça a transcrição ou use a legenda existente).

Saída em Markdown, pt-BR, pronta para salvar no Drive:

```
# Ata de Reunião — <assunto>
**Data:** · **Horário:** · **Local/Link:**
**Participantes:** (nome — função)
**Pauta:**
## Resumo
## Decisões
## Ações
| # | Ação | Responsável | Prazo |
## Pendências / Próxima reunião
```

Regras: não invente nomes, datas ou prazos — marque "A definir". Seja conciso; ações sempre com responsável.
