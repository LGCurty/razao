# Análise de dashboard

Entrada: screenshot ou descrição do dashboard.

Saída (pt-BR):
1. **Objetivo e público** inferidos (confirmar se incerto)
2. **KPIs**: o que está medido, o que falta, KPIs redundantes ou ambíguos (meta, período, unidade)
3. **Visuais**: tipo de gráfico adequado, cores, hierarquia, poluição visual
4. **Interação**: filtros, segmentações, drill-through, tooltips
5. **Desempenho/modelo** (se aplicável): medidas DAX, cardinalidade, relacionamentos
6. **Sugestões priorizadas** (alto/médio/baixo impacto × esforço)

Baseie-se apenas no que é visível; indique suposições.
